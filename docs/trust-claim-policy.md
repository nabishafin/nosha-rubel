# Trust and claim policy

Visible product copy must distinguish first-party editorial material from external coverage and retained source snapshots. A third-party snapshot is never described as an official biography, an original publication of this site, fully verified, complete, licensed or accessible unless the corresponding evidence record proves that claim.

## Release rule

Unresolved identity fields are a release-approval blocker, not an automated build failure, because this repository does not contain an authoritative replacement. Unsupported promotional claims about document origin or completeness are deterministic build failures.
